# NEQUE-11.2.2 — Doble guardado en el runner

## Estado

Terminado.

## Historia relacionada

`HU-11.2`

## Hallazgo de auditoría

[`W-1`](../../../auditoria/2026-09-18-auditoria-app-alumno.md) — ver el informe para el detalle y la severidad.

## Qué hace

Cambia `saving` de `computed(() => false)` a un `signal` real y bloquea «Guardar y volver» mientras `finish()` está en curso.

## Por qué

El `computed` devolvía siempre `false`, así que el botón nunca se deshabilitaba: un doble toque persistía la sesión dos veces y navegaba dos veces.

## Criterios de aceptación

- [x] El botón se deshabilita mientras se guarda y se libera al terminar.
- [x] Un doble toque llama a `complete()` una sola vez.
- [x] Hay spec que cubre el segundo toque.
