# NEQUE-11.5.1 — Ticket de recuperación de un solo uso

## Estado

Terminado.

## Historia relacionada

`HU-11.5`

## Hallazgo de auditoría

[`F-1`](../../../auditoria/2026-09-18-auditoria-app-alumno.md) — ver el informe para el detalle y la severidad.

## Qué hace

`verifyOtp()` pasa a devolver `PasswordResetTicket` en vez de `AuthSession`, y se agrega `resetPassword(ticket, newPassword)`. El adapter mock emite el ticket, lo invalida al consumirlo y reemplaza la contraseña de la cuenta.

## Por qué

Verificar un código de seis dígitos abría sesión directamente: el OTP equivalía a la contraseña y la anterior seguía vigente.

## Criterios de aceptación

- [x] `verifyOtp()` no devuelve sesión.
- [x] El ticket sirve una sola vez; reutilizarlo devuelve `unauthorized`.
- [x] Tras el cambio, la contraseña anterior deja de servir en el login y la nueva funciona.
