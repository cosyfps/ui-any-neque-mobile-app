# NEQUE-11.0.3 — Regla de tokens en la documentación

## Estado

Terminado.

## Historia relacionada

`HU-11.0`

## Qué hace

Documenta en `CLAUDE.md` cuándo usar `--nq-primary` y cuándo `--nq-primary-strong`, el mínimo táctil de 44×44 con `nq-tap-halo`, y la directiva `nqSheetTrap`.

## Por qué

Sin la regla escrita, el próximo componente vuelve a poner texto teal sobre blanco y el problema de contraste reaparece pantalla por pantalla.
