# NEQUE-11.1.5 — Baja de CSS muerto

## Estado

Terminado.

## Historia relacionada

`HU-11.1`

## Qué hace

Elimina 18 clases globales que no usa nadie y el `nq-scroll` inerte de seis páginas.

## Por qué

Paga el CSS que suman los targets de 44px y el bloque de motion, y protege el budget de 500 kB. `.nq-scroll` además era inerte: el scroll real lo hace `.layout-content`.
