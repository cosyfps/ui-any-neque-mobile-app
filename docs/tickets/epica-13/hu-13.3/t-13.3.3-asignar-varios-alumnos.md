# NEQUE-13.3.3 — Hoja para asignar una rutina a varios alumnos

## Estado

Terminado — `1b1eb88` (2026-09-26), publicado en la release 0.0.3.

## Historia relacionada

`HU-13.3`

## Qué hace

Desde la biblioteca, una hoja con la lista de alumnos activos permite asignar la rutina a varios a la vez.

## Por qué

Con rutinas compartidas, asignar de a un alumno obligaba a repetir el flujo por cada uno.

## Criterios de aceptación

- [x] Se pueden marcar varios alumnos y guardar una sola vez.
- [x] Sin alumnos activos la hoja lo explica en vez de mostrarse vacía.
