# NEQUE-13.2.1 — Menos aire sobre las pantallas con pestañas

## Estado

Terminado — `65cee2c` (2026-09-26), publicado en la release 0.0.2.

## Historia relacionada

`HU-13.2`

## Qué hace

Crea el token `--nq-page-pt` (8px) y lo usa como padding superior de las nueve páginas con pestañas, en vez de 24px fijos.

## Por qué

El shell ya suma el `safe-area-inset-top`. Con 24px más, en un iPhone con notch el primer vistazo de cada pestaña se veía hundido.

## Criterios de aceptación

- [x] Las nueve páginas con pestañas leen `--nq-page-pt`.
- [x] En iPhone con notch el título queda justo bajo la barra de estado, sin franja vacía.
