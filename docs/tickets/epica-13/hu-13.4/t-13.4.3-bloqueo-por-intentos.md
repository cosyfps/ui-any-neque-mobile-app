# NEQUE-13.4.3 — Bloqueo temporal por intentos fallidos

## Estado

Terminado — `9cd1006` (2026-09-27), publicado en la release 0.0.3.

## Historia relacionada

`HU-13.4`

## Qué hace

El adapter de auth bloquea un correo durante 5 minutos después de 5 intentos fallidos seguidos y responde `too_many_attempts`. El login muestra el aviso.

## Por qué

Sin límite, el login aceptaba intentos ilimitados. El control definitivo es del BFF; el mock deja el contrato y la UI listos.

## Criterios de aceptación

- [x] El sexto intento dentro del bloqueo falla sin validar la contraseña.
- [x] Pasados los 5 minutos el correo vuelve a intentar.
- [x] Un ingreso correcto reinicia el contador.

## Definición de terminado

- [x] Criterios de aceptación cumplidos.
- [x] `.spec.ts` incluido o actualizado cuando el ticket toca código.
- [x] `lint`, `typecheck`, `format:check`, `test:coverage` y `build` en verde.
- [x] Validado en la IPA.
- [x] Tablero de `docs/BACKLOG.md` actualizado.
