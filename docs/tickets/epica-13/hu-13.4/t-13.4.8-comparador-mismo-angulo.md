# NEQUE-13.4.8 — Comparador: fotos solo del mismo ángulo

## Estado

Terminado — `0be0734` (2026-09-27), publicado en la release 0.0.3.

## Historia relacionada

`HU-13.4`

## Qué hace

Cada fecha del comparador abre una hoja con las fotos del ángulo activo (frente, perfil o espalda). Las fechas se muestran como `dd/mm/aaaa`.

## Por qué

Comparar un frente con una espalda no dice nada. Con meses de diferencia, los formatos de fecha de largo variable se veían disparejos.

## Criterios de aceptación

- [x] El selector solo ofrece fotos del ángulo activo.
- [x] Las fechas del comparador usan `dd/mm/aaaa`.
