# NEQUE-8.1.1 — Agrega el shell del alumno con sus cuatro pestañas

## Estado

Terminado.

## Historia relacionada

`HU-8.1`

## Qué hace

Crea `StudentLayoutPage` con el tab bar de Inicio, Mi rutina, Progreso y Perfil, y `student.routes.ts` con las rutas hijas y los providers de la feature.

## Por qué

Los providers van en UNA sola ruta contenedora. Dos `providers` hermanos crean dos injectores y por tanto dos juegos de adapters: el runner cerraría la sesión en su copia y el shell nunca vería el cambio.

## Criterios de aceptación

- [x] La pestaña activa se deriva de `NavigationEnd`, ignorando los query params.
- [x] Una ruta hija mantiene encendida la pestaña que la abrió.
- [x] El shell exige rol de alumno con `canMatch`.
- [x] El runner y la agenda comparten el mismo injector que las pestañas.
