# NEQUE-7.3.3 — Agrega SessionFacade

## Estado

Terminado.

## Historia relacionada

`HU-7.3`

## Qué hace

Crea la facade de sesión con `user`, `role`, `profileId`, `isAuthenticated`, `status` y `loginError`, y los métodos `restore`, `login`, `adopt`, `signOut` y `clearError`.

## Por qué

Es la única facade que otras facades pueden inyectar: les entrega el `profileId` sin que cada feature lo resuelva por su cuenta.

## Criterios de aceptación

- [x] `restore()` rehidrata una sesión vigente y descarta una expirada o con fecha no parseable.
- [x] `restore()` no vuelve a leer el storage si ya hay sesión en memoria.
- [x] `login()` devuelve la ruta inicial del rol, o null si falló.
- [x] `signOut()` limpia el estado local aunque el backend falle.
