# NEQUE-7.3.1 — Define el dominio de autenticación y sus puertos

## Estado

Terminado.

## Historia relacionada

`HU-7.3`

## Qué hace

Crea `AuthUser`, `AuthSession`, `Credentials` y `UserRole`, los puertos `AUTH_PORT` y `SESSION_STORAGE_PORT`, y la función pura `homeRouteForRole()`.

## Por qué

`AuthUser.profileId` apunta al Trainer o al Student según el rol y viaja en la sesión: evita que cada feature necesite un `getByUserId` propio.

## Criterios de aceptación

- [x] Los métodos del puerto devuelven `Observable`, para que el adapter HTTP encaje sin cambiar firmas.
- [x] `SESSION_STORAGE_PORT` es síncrono: el guard decide antes de resolver la ruta.
- [x] `homeRouteForRole()` cubre los dos roles.
