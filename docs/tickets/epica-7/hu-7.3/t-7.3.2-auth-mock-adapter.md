Terminado.

## Qué hace

Crea `AuthMockAdapter` con cuentas semilla de entrenador y alumno, y `LocalStorageSessionAdapter` para persistir la sesión.

## Criterios de aceptación

- [x] Las dos cuentas semilla autentican y devuelven el rol y el `profileId` correctos.
- [x] El correo se normaliza: mayúsculas y espacios no impiden el ingreso.
- [x] Credenciales incorrectas fallan con `invalid_credentials`, sin distinguir si el error fue el correo o la contraseña.
- [x] Toda lectura y escritura de `localStorage` va en try/catch: en modo privado la app se comporta como si no hubiera sesión.
- [x] Dos instancias del adapter no comparten estado.
