# NEQUE-7.1.5 — Separa los mixins de las clases globales del theme

## Estado

Terminado.

## Historia relacionada

`HU-7.1`

## Qué hace

Extrae los tres mixins de `_components.scss` a `_mixins.scss` y deja en `_components.scss` solo las clases globales, que importa `styles.scss` una única vez. Las páginas pasan a usar `_mixins.scss`.

## Por qué

`_components.scss` mezclaba 3 mixins con ~555 líneas de CSS global. Cada `@use` de una página emitía todo ese CSS dentro de su estilo scopeado: `start.page.scss` compilaba a 12.44 kB desde 4.0 kB de fuente y dos páginas ya excedían el budget de 8 kB. Con las pantallas de la Épica 8 habrían sido ~150 kB de CSS duplicado.

## Criterios de aceptación

- [x] `_mixins.scss` no emite CSS: solo contiene `@mixin`.
- [x] Ninguna página hace `@use` de `_components.scss`.
- [x] `build:prod` deja de reportar los dos warnings de budget por estilo de componente.
- [x] Las pantallas existentes se ven igual que antes del cambio.
