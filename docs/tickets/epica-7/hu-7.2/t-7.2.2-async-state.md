# NEQUE-7.2.2 — Agrega AsyncState como único dueño de loading, error y empty

## Estado

Terminado.

## Historia relacionada

`HU-7.2`

## Qué hace

Crea `AsyncState<T>` en `application/shared`: signals de `data`, `error` y `loading`, un `viewState()` que mapea 1:1 a `<nq-page-state>`, y `load`, `reload`, `set`, `fail` y `reset`.

## Por qué

Centralizar las ramas de estado en una clase evita que cada facade las reinvente y que cada página deje alguna sin cubrir.

## Criterios de aceptación

- [x] `viewState()` devuelve loading, error, empty o success según los datos, sin que la página decida nada.
- [x] Un valor nulo recibido se distingue de "todavía no llega nada": el primero es empty, el segundo loading.
- [x] Iniciar una lectura cancela la anterior y descarta su emisión tardía.
- [x] `reload()` repite la última fuente registrada y no hace nada si nunca se llamó a `load()`.
- [x] La heurística de vacío por defecto cubre null, undefined, arreglo vacío y objetos con `length` 0.
